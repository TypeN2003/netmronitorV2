# เปิด SSH ด้วย PuTTY จากหน้าเว็บ NetMonitor

ปุ่ม SSH (ไอคอน terminal) ในหน้า Devices เป็นลิงก์ `ssh://<IP อุปกรณ์>`
ต้องบอก Windows ก่อนว่าให้เปิดลิงก์แบบนี้ด้วย PuTTY ทำครั้งเดียวต่อเครื่อง

## ติดตั้ง

1. ติดตั้ง PuTTY (https://www.putty.org) ถ้ายังไม่มี
2. ดับเบิลคลิก `install.cmd` ในโฟลเดอร์นี้ ไม่ต้องใช้สิทธิ์ Administrator
3. ในหน้า Devices กดไอคอน terminal เบราว์เซอร์จะถามว่าเปิดลิงก์ไหม กด "เปิด"
   (ติ๊ก "อนุญาตเสมอ" ไว้ จะได้ไม่ต้องถามทุกครั้ง)

PuTTY จะเปิดและต่อไปที่ IP ของอุปกรณ์ แล้วถาม `login as:` ตามปกติ

## ถอนการติดตั้ง

รัน `uninstall.ps1` ด้วย PowerShell

## ความปลอดภัย

`ssh-launch.ps1` ยอมรับเฉพาะลิงก์รูปแบบ `ssh://[user@]host[:port]` ที่มีแค่ตัวอักษร ตัวเลข `.` `-` `_`
แล้วส่งต่อให้ PuTTY เป็น argument เท่านั้น ลิงก์จากเว็บอื่นที่พยายามแทรกคำสั่งจะถูกปฏิเสธ
